=== News Publisher Bridge for Diafaneia ===
Contributors: karago
Requires at least: 6.4
Requires PHP: 7.4
Stable tag: 1.0.0

Secure REST publishing bridge for the Windows News Publisher application on diafaneia.eu.

Features:
- Application Password authentication
- edit_posts and publish_posts capability checks
- diafaneia.eu wrong-site protection
- REQUEST_ID idempotency
- existing category validation
- Yoast SEO title, description and focus keyword mapping
- optional featured image support
- Draft and Publish modes

No credentials or secrets are stored by this plugin.
